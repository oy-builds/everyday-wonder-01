# The Ghost Clocks In

A make.fun entry for "Everyday Wonder, Two Days to Find the Line": one
sentence, at most 200 characters, on a small moment of wonder in everyday
life.

`main.ts` (Node 22, standard library only) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Every dawn the tea seller pours his first cup and the steam curls up like a small ghost clocking in for work.

Run it with `node main.ts`.
